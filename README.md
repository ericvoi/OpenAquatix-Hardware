# OpenAquatix Hardware
PCB files for the open-source underwater acoustic modem: OpenAquatix.

OpenAquatix is an open-source underwater acoustic modem that provides a flexible and performative interface for research applications and small-scale hobby projects. Key hardware features include:

1. USB 2.0 interface at 480Mbps
2. In-built power consumption monitoring
3. Ambient pressure and temperature sensing
4. Low-noise analog front-end
5. 6th order bandpass filter on input signals
6. Primary processor is an STM32H723 (512 kB flash and RAM) running at 480 MHz for onboard processing of messages
7. Output power of 30W continuous, 60W peak.
8. Reverse polarity and surge protection
9. Standby power consumption of 2 mW
10. Listening power consumption of 100 mW
11. Active processing power consumption of 1 W
12. Fully customizable daughter card for limitless AUV/User - Modem communication protocols (Ethernet, RS232, RS485, CAN, Modbus, etc.)
13. Cost of each board (transducer excluded) fully assembled at quantities of 5+: $110 USD
14. Input feedback network to test novel modulation/demodulation techniques on real hardware
15. Output feedback network to calibrate phase non-linearities in the output chain
16. 2 MB external flash
17. SWD debugging interface
